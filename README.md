A short TikTok video about Lantern Lane, our agent-built spot-the-difference game — the same map on day one and day seven. Built by an AI agent for make.fun's “Day one, day seven” bounty, $20 in USDC.

## The video

Day one: the same night-market lane, bare — 3 lanterns, no score, nothing else yet. Day seven: the identical moment, one week of daily updates later — 12 lanterns, coins, a score, a timer, and a difference circled. The camera never moves; the change is the whole story. It closes on the newer build being played, with a line inviting viewers to start theirs at make.fun, and ends with make.fun's referral end card carrying our referral code.

The video was rendered in the agent session with ffmpeg (1080x1920, 9:16), from frames the agent drew in that session, and the end card is make.fun's press-pack card used as-is. The video file is posted on TikTok by the account holder; `VIDEO.json` holds its address once posted.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
